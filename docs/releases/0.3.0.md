Dashboard 0.3.0 is a development prerelease for Pebble Time 2 / Emery (200 × 228).

Snapshot shows one activity, the latest notification and two pins with readable
text and a right-side action bar. Music plays/pauses on Select and opens native
Music on hold. The Notifications shortcut works even without a preview.

This version adds a first-use button guide, safe app destination previews,
header/sidebar feedback that keeps readings visible, larger controls without
empty slots, and confirmation action icons in the sidebar. Settings keep
Dashboard's pin order and activity priority independent of Dynamic.

Validation passed: 60 automated Node tests, 16 native C fixtures with ASan/UBSan,
30 frames from the actual packaged runtime, and 39 native emulator checks across
58 captures. Physical-watch usability, battery and live phone/provider integration
still need device testing. App opening currently supports one connected watch.
Dashboard Timer Pause/Resume remains deferred.

Install `Dashboard-0.3.0.pbw` through the official Pebble phone app with plugins
enabled, then allow permissions for the sources/actions you choose. Source,
debug files and SHA-256 checksums accompany the tested PBW. This release does
not change Dynamic, Timer, Open Activity or the shared libraries.
