Fixes the missing Activity priority list in Dashboard settings.

Dashboard previously requested discovery from its settings plugin, where that
API is unavailable. Discovery now runs in the app's phone-side code, matching
Dynamic's supported approach, and includes installed providers with no active
activity. Settings display discovery errors and retry controls directly.

**After installing, open Dashboard on the watch once to discover providers.**
The settings page refreshes when Dashboard becomes available and can use its
saved public provider list after the watchapp closes. Your pin order, activity
priority and visibility preferences are preserved. No live activity, reading or
notification content is cached.

Validated with 66 automated Node tests, 24 browser checks using the actual config
handlers and separate supported SDK contexts, and the actual packaged runtime
plus native C frame decoding. The native watch UI and shared libraries are
unchanged. This remains an Emery development prerelease; live phone/provider
integration and physical-watch checks remain separate.
